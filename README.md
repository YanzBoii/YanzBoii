## Salut, moi c'est YanzBoii

Je développe des outils que j'utilise au quotidien — des trucs simples,
rapides, qui règlent un problème précis.

### Projets

**[YanzVoice](https://github.com/YanzBoii/YanzVoice)** — Dictée vocale pour
Windows. Tu parles, le texte se colle tout seul dans l'application active.
Transcription par Groq Whisper, audio encodé en Opus pour tenir sur une
connexion faible.

`Python` · `PyQt6` · `Groq API`

### Ce que j'aime faire

qui démarrent vite.
